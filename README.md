# Bijli Manager Pro (HTML)

Sirf `index.html` badalna hai. Commit karte hi app update ho jata hai.

## Ek baar setup
Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / folder `/ (root)` > Save.
1-2 min baad link banega: https://USERNAME.github.io/REPO-NAME/

## Update kaise karein
`index.html` ko edit/replace karke commit karo. APK dobara banane ki zaroorat nahi.
APK agle open par (internet ho to) nayi version utha leti hai.

Zaroori: repo ka naam ya username baad me mat badalna, warna link badal jayega aur app ka data alag ho jayega.
